# CSE470: Software Engineering
## Food-Ordering-App, MERN

The Food-Ordering-App I have developed uses MERN Stack, an MVC architecture. 

As the actions act as codebase, each action has been unit tested. The unit tests are in the [actions](/client/src/actions) folder: **client > src > actions.**
There are three action files:
* cartAction
* pizzaAction
* userAction
